# 测试与验收

## 记录规则
每次记录日期、环境、输入/操作、观察结果、证据位置和未测范围。
检查配置能解析、模拟链路通过、桌面原生运行、真实教务、其他机器打包运行、服务器部署分别记录。
当前以下验收案例均为计划，除末尾环境记录外，尚未执行。

## 核心业务自动验证
- 同名不同教学班：筛选后保留正确的教学班 ID，任务绑定具体班级。
- 满员 → 有位：仅通知模式不提交选课；自动模式在允许的任务上调用提交。
- 有位持续存在：相同状态不反复推送；成功任务不继续提交。
- 余量字段异常：不执行选课，保留可读错误。
- 任务取消：发起提交前再次检查取消状态；已在外部执行的请求不宣称能撤销。
- 会话失效：暂停等待登录，不把登录 HTML 当成空列表。
- 网络超时/限频：请求有期限，退避并记录下次检查，不能无限紧密循环。
- 空位被其他人占用：归类为满员并继续等待，而不是显示成功。
- 提交超时但实际成功：核验已选后停止，无第二次提交。
- 结果无法确认：NEEDS_REVIEW，暂停自动提交。
- 通知发送失败：任务成功状态保留，只重试通知。

测试使用可控制的模拟适配器、时钟和等待机制，避免为了验证退避真的等待数十秒。
测试断言用户可观察结果、状态与外部动作次数；不为每个属性或实现细节写重复测试。

## 数据库与进程组合验证
- 重启后任务 ID、模式、所属用户和状态仍存在。
- 恢复 ENROLLING 任务时先核验实际结果，不盲目重发。
- 单实例约束成立；允许多实例之前测试原子领取、租约到期恢复与并发执行。
- 创建重复任务被拒绝或明确复用；取消操作重复调用结果稳定。
- 任务状态和待发送通知事件一致；进程中断后能补发通知。
- 迁移前后的数据可以恢复，备份不只是文件存在。

## 原生桌面验收
- 查询期间窗口可拖动，按钮仍响应。
- 登录失效、有余位、提交中、待复核、已成功等状态清晰。
- 最小化仍执行；隐藏到托盘与退出行为按产品约定分别验证。
- 控件更新在主线程；后台异常有反馈。
- 真实来源与模拟来源有明确标识。
- 本机通知实际出现，不把生成事件视为通知已送达。

## 真实教务验收
- 用户自行登录，按真实教学班对照查询结果和当前可选状态。
- 教务页面与适配器使用同一学期、同一教学班和同一账号。
- 真实会话失效、重新登录、查询恢复分别记录。
- 真实选课需明确目标范围；以真实已选列表或学校确认页面为成功证据。
- 记录测试时余量和结果，不编造实测数据；失败和无空位也保留。
- 凭据、完整响应和 HAR 只在受保护的本机位置处理；共享证据脱敏。

## Web 与部署验收
- A/B 两个测试身份互相访问任务、取消任务、事件和通知设置时均被拒绝。
- 服务器用网站身份确定 owner_id；伪造请求中的 owner_id 无效。
- 学校会话不返回给页面、不写日志；退出/撤销会话可控制后续执行。
- 关闭网页后 worker 继续；浏览器重新打开可查看同一个任务。
- API 进程重启后 worker 工作不受影响；worker 重启后按规则恢复。
- 服务器确实能访问学校查询接口，不用本机可达替代。
- 实际选定的通知渠道收到消息；重试与去重结果分别核验。
- 进程自动启动、数据库迁移、备份恢复、HTTPS 和总请求限频实际运行验证。
- 增加并行 worker 或用户数量前，重新评估竞争、限频和数据隔离。
